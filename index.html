☁️ Синхронизация с Google Drive

База данных автоматически сохраняется в JSON-файл kegcontrol_cloud_db.json на вашем Google Диске и синхронизируется между устройствами владельца и водителя.

Статус: не подключено.
Как получить Client ID за 2 минуты:
1. Откройте Google Cloud Console → создайте проект → включите Google Drive API.
2. В разделе Credentials → Create Credentials → OAuth client ID выберите Web application и добавьте URL вашего приложения в Authorized JavaScript origins.
3. Скопируйте полученный Client ID выше. Один и тот же Google-аккаунт (или общий доступ к файлу) обеспечит мгновенный обмен данными.
